# Social Media Thing: Button Information

This folder documents the core interaction buttons and their intended behavior.

## Buttons

- [Heart](./heart.md): Normal appreciation.
- [Salt](./salt.md): Limited, stronger appreciation.
- [Drink](./drink.md): Unlimited saving/collecting.
- [Mix](./mix.md): Connects a post to an existing Tonic.

These mechanics may change as the project develops.
