# Social Media Thing: Project Information

The Info folder is the persistent design record for Social Media Thing. The master specification is the main source of truth for the product design.

## Master specification

- [Platform Specification](./platform-spec.md): detailed product, navigation, content, collection, account, visual, and development decisions.

## Core interaction documentation

- [Heart](./heart.md): normal appreciation and the Love Potion.
- [Salt](./salt.md): limited special appreciation and the Salt Jar.
- [Drink](./drink.md): unlimited saving/collecting.
- [Mix](./mix.md): adding Posts to Tonics or Barrels and creating connection relationships.

The project should keep this documentation synchronized with new design decisions. When a later design decision changes an earlier idea, update the relevant documentation rather than relying on the conversation history.
