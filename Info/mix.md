# Mix

The Mix button creates a connection between the current post and an existing Tonic.

## Basic behavior

1. The user opens a post.
2. The user selects Mix.
3. A menu shows the user's existing Tonics.
4. The user selects a Tonic.
5. The current post is added to that Tonic.
6. The connection becomes part of the larger Potion Tree.

A user can also have an option to create a new Tonic if none of their existing Tonics fit.

## Why Mix exists

Mix is different from Heart, Salt, and Drink. It is not primarily an appreciation action. It is a way for users to connect pieces of content together.

The goal is for many small user-created connections to form a larger network that other people can explore through Potion Trees.

## Important UX principle

Mix should be quick. Users should not need to manually construct a complicated tree or spend a long time organizing posts. The system should create the tree automatically from the connections people make.
